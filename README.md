# 🚖 Taxi Data Analysis

## Overview
This project analyzes a taxi trips dataset using Python, NumPy, and Matplotlib in a Jupyter Notebook. The analysis includes calculating average speed, total revenue, trip statistics, and visualizing the distribution of taxi fares.

## Dataset
The project uses the `taxis.csv` dataset, which contains information about taxi trips, including:
- Trip distance
- Trip duration
- Fare amount
- Pickup month
- Revenue

## Features
- Calculate the average speed of taxi trips.
- Count trips taken during February.
- Find the number of trips with revenue greater than $50.
- Calculate the total revenue.
- Find the longest trip.
- Visualize the distribution of taxi fares using a histogram.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Jupyter Notebook

## Files
```
Taxi_Analysis.ipynb   # Jupyter Notebook
taxis.csv             # Dataset
README.md             # Project documentation
```

## How to Run
1. Clone this repository.
2. Open the project in Jupyter Notebook or JupyterLab.
3. Make sure `taxis.csv` is in the same folder as the notebook.
4. Run all notebook cells.

## Example Output
The notebook calculates:
- Average taxi speed
- Total revenue
- Number of February trips
- Trips with revenue greater than $50
- Histogram showing the distribution of taxi fares
