# 🚖 Taxi Data Analysis with Python

Welcome to my **Taxi Data Analysis** project! This project explores a taxi trips dataset using **Python**, **NumPy**, and **Matplotlib** to perform data analysis and create visualizations. The goal is to extract meaningful insights from the data by calculating key statistics and presenting the results in a clear and organized way.

---

## 📖 Project Overview

In this project, I analyzed a taxi dataset containing information about thousands of taxi trips. Using Python and NumPy, I performed calculations on the dataset and answered several analytical questions, such as:

- 🚗 What is the average speed of taxi trips?
- 📅 How many trips were taken in February?
- 💰 How many trips generated more than **$50** in revenue?
- 📈 What is the total revenue from all trips?
- 🛣️ What was the longest trip recorded?
- 📊 What does the distribution of taxi fares look like?

The project also includes a histogram to visualize the distribution of taxi fares.

---

## 📂 Dataset

The project uses the **`taxis.csv`** dataset, which contains information such as:

- 📅 Pickup month
- 📍 Trip distance
- ⏱️ Trip duration
- 💵 Fare amount
- 💰 Revenue
- 🚖 Other trip-related information

---

## ✨ Features

✅ Calculate the **average speed** of all taxi trips.

✅ Count the **number of trips in February**.

✅ Find the **number of trips with revenue greater than $50**.

✅ Calculate the **total revenue** generated.

✅ Identify the **longest trip** in the dataset.

✅ Visualize the **distribution of taxi fares** using a histogram.
